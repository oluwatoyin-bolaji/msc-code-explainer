Pre-Test: Code Comprehension

Read the Java code below and answer the questions. Do not use any external help or the AI tool.

Java Code Snippet 
class Animal {
    String name;

    Animal(String name) {
        this.name = name;
    }

    void makeSound() {
        System.out.println("Some sound");
    }
}

class Dog extends Animal {
    Dog(String name) {
        super(name);
    }

    @Override
    void makeSound() {
        System.out.println("Woof");
    }
}

public class Main {
    public static void main(String[] args) {
        Animal a = new Dog("Rex");
        a.makeSound();
    }
}

1. What is printed when the program runs?

2. What does super(name) do in the Dog constructor?

3. The variable a is of type Animal but holds a Dog object. What is this called?

4. What does @Override indicate?

5. If we removed the makeSound() method from Dog, what would a.makeSound() print?
