Post-Test: Code Comprehension

Read the Java code below and answer the questions. Do not use any external help or the AI tool.

Java Code Snippet 
class Vehicle {
    int speed;

    Vehicle(int speed) {
        this.speed = speed;
    }

    void describe() {
        System.out.println("This vehicle travels at " + speed + " km/h");
    }
}

class Car extends Vehicle {
    Car(int speed) {
        super(speed);
    }

    @Override
    void describe() {
        System.out.println("This car drives at " + speed + " km/h");
    }
}

public class Test {
    public static void main(String[] args) {
        Vehicle v = new Car(120);
        v.describe();
    }
}

1. What is printed when the program runs?

2. What is the relationship between Car and Vehicle?

3. What does super(speed) do?

4. Why does v.describe() call the Car version of describe?

5. If we removed the describe() method from Car, what would v.describe() print?
